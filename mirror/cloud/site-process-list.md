# Site Process List

You can view running mariadb queries in your site by opening **Insights** tab, and then **Reports ->** **Process List Report**

![](https://docs.frappe.io/files/XnwpZ4e.png)

![](https://docs.frappe.io/files/jsXP8Fw.png)
