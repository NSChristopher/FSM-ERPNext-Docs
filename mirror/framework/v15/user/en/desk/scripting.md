# Scripting

Frappe framework allows you to script the standard models and views directly within the framework without additional code.

Different ways of Scripting:

1.  [Client Script](https://docs.frappe.io/framework/v14/user/en/desk/scripting/client-script)
2.  [Server Script](https://docs.frappe.io/framework/v14/user/en/desk/scripting/server-script)
3.  [Script Report](https://docs.frappe.io/framework/v14/user/en/desk/reports/script-report)
4.  [System Console](https://docs.frappe.io/framework/v14/user/en/desk/scripting/system-console)
