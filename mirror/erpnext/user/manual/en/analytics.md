# Analytics

This part of the Agriculture module is used for tracking data and report generation

All the data pertaining to the following doctypes can be tracked by ERPNext

-   Plant Analysis
-   Soil Analysis
-   Water Analysis
-   Soil Texture
-   Weather
-   Agriculture Analysis Criteria
