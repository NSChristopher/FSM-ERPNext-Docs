# Add columns in Standard Report and Export

In **Standard Reports** of **ERPNext** such as _SOA, Accounts Receivable/Payable etc_, we provide an option to **Add/Remove Columns** from the documents and display it in the Report, these columns are only meant for reference at that particular moment of time.  
![](https://docs.frappe.io/files/wwG7ihj.png)  
If the User needs to _Export_ along with the changes made by him in the Report, the User needs to Save the Report and then _Export_ it.  
![](https://docs.frappe.io/files/lFCoBXj.gif)
