# Complete Setup

If you have installed Insights on a brand new site, you will need to set up your account. Visit your site that has Insights installed, and you should see a setup wizard.

![Setup Wizard](https://docs.frappe.io/files/insights-setup-wizard.png)  
_Setup Wizard_

To complete the setup you will need to enter basic information like your country, name, email, and password. Make sure to remember your email and password as this is going to be your [admin account](https://docs.frappe.io/miscellaneous/faq#admin-account).

Once you have gone through the setup wizard, you will be redirected to the Insights Workbook page where you can see a sample workbook created based on the demo data

![Workbook List](https://docs.frappe.io/files/insights-workbook-list.png)  
_Sample Workbook_
